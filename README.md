# 🧠 Python Quiz Game

A simple interactive quiz game built with Python where players answer multiple-choice questions and earn points for correct answers.

## 📌 About the Project

This project is part of my Python learning journey. It is designed to practice programming fundamentals by creating a quiz with questions, answer checking, and a scoring system.

## 🎮 How to Play

1. Run the Python program.
2. Read each question carefully.
3. Choose your answer from the given options.
4. Receive feedback on whether your answer is correct or incorrect.
5. Earn points for correct answers.
6. Check your final score at the end of the quiz.

## ✨ Features

- Multiple-choice questions
- Interactive user input
- Automatic answer checking
- Score tracking
- Correct and incorrect answer feedback
- Beginner-friendly command-line interface

## 🛠️ Technologies Used

- Python
- VS Code

## ▶️ How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/python-quiz-game.git
   ```

2. Navigate to the project folder:

   ```bash
   cd python-quiz-game
   ```

3. Run the program:

   ```bash
   python quiz_game.py
   ```
